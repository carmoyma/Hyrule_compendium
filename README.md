# Hyrule Compendium

This is my personal project to explore the **Hyrule Compendium** from *The Legend of Zelda: Breath of the Wild*.  
It’s a web app that lets you **browse weapons, enemies, creatures, and equipment**, check their stats, and filter them by category.

## What it does
- Search for items, creatures, treasures, enemies, and equipment
- Filter entries by category
- View detailed drops and stats, including attack, defense, durability, and elemental properties
- Simple and clean interface for desktop and mobile

## Tech used
- **HTML5** – Structure and content  
- **CSS3** – Styling and responsive design  
- **JavaScript** – Fetching data from the API and interactivity  
- **Fetch API** – Connects to the *Hyrule Compendium* API
